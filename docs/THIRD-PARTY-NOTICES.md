## 4. Tournament Dataset Provenance
The bundled JSON files in `euro2024_data/` (`20` teams, `220` players, `5` sample matches dated `2024-07-22` to `2024-07-26`, `19` goal events) and the `2` static entries in `NewsViewModel.swift` are original sample project data created for the SwiftUI/Firebase course application. They do **not** represent official historical UEFA Euro 2024 match results, complete 24-team squads, or live tournament feeds.
