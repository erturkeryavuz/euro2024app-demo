Third-Party Notices & Media Provenance (docs/)

This interactive web showcase (docs/) presents the Euro2024App SwiftUI & Firebase project as an unmonetized, static software-engineering portfolio demonstration. It is not affiliated with, endorsed by, or sponsored by UEFA, any national football federation, any club, or any athlete.

1. Original Graphics Authored for This Showcase (25 SVGs)

The following vector graphics in docs/assets/ are original works created specifically for this static showcase (containing no third-party trademarks, stock watermarks, or UEFA branding):

  • docs/assets/icons/analyzes.svg, docs/assets/icons/profile.svg, docs/assets/icons/players.svg, docs/assets/icons/news.svg — Original 120×120 Home/Main tile icons matching ContentView.swift / MainView.swift.
  • docs/assets/neon-mesh-bg.svg — Original dark neon geometric polygon backdrop reproducing the matches bg3 visual palette.
  • docs/assets/teams/t1.svg through docs/assets/teams/t20.svg — 20 original circular geometric national-color monogram badges replacing copyrighted football federation crests.
